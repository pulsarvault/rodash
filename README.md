# RoDash: Open Source TypeScript Kit.
To install dependencies:

```bash
bun install
```

To build all files into dist/:

```bash
bun run build
```
To run tests:

```bash
bun test
```

This project was created using `bun init` in bun v1.3.14.
[Bun](https://bun.com) is a fast all-in-one JavaScript/TypeScript runtime.
